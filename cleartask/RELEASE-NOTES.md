# OIA 工作台 0.5.0

ClearTask 更名为 OIA 工作台（OIA Workspace · One Is All），保持原工作区和旧版升级兼容。

- 新首页：集中显示今日计划、待办概览、最近备忘录、完成回顾、日历与提醒。
- 全局配色：自定义主色，统一背板、模块、选中态；替换为十三组协调色系。
- 模块材质：应用内背板高斯模糊，透明度和模糊半径分别可调；文字、输入区不透明。不是 Fences 式桌面实时透视，也不声称实现 Apple 的系统液态玻璃折射。
- 底部导航：可将清单、项目或标签改为横向玻璃风格导航，支持横向滚轮、悬停和按下反馈。
- 备忘录：单行工具栏，超出部分横向滚动、不显示滚动条；末端反馈；加入字号加减。
- 目录：仅保留一个新建入口，目录显示开关位于目录侧，支持拖动调整宽度。
- 文档：标题和正文共享滚动区域，保存状态置于底部。
- 中文输入：组词期间不读取富文本或调整文档布局；草稿提取延后至输入停顿，合并草稿落盘，保留焦点、原生句柄和选区。
- 页面导航：修复设置返回同一备忘录入口不响应；取消整页截图过渡；保留各级返回。
- 品牌：更新窗口、安装卸载、托盘及通知名称，新矢量图标统一打包；保留内部标识确保旧数据与更新兼容。
- 更新下载：显示当前线路，所有线路失败后列出失败原因，签名及完整性校验不降低。

验收包含云端界面渲染、布局/滚动/输入法消息生命周期、旧版升级、数据保留、失败回滚与发布后更新链路。真实用户输入法和境内各运营商网络不以云端测试替代。
