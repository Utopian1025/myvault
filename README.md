# 像素小窝 · Pixel Nest

住在你桌面底部的像素小伙伴：猫咪、柴犬、兔兔、仓鼠、企鹅、狐狸（还有一只要靠神秘的蛋才能孵出来）。
它们会跟着你的鼠标转眼珠、陪你打字、提醒你喝水伸懒腰，也有自己的小日子：吃饭、喝水、上厕所、睡觉、发呆、一起玩、想你、想一个人待着。

## 安装（给朋友用）

Windows：双击 `像素小窝-安装包-x.x.x.exe` → 选择安装位置 → 完成。桌面和开始菜单会有图标。
第一次运行如果 Windows 弹出“已保护你的电脑”，点「更多信息 → 仍要运行」（程序没有付费签名）。

卸载：「设置 → 应用 → 像素小窝 → 卸载」。会一并删除存档、缓存和开机自启项，不留残留。

macOS：打开 `像素小窝-x.x.x.dmg`，把图标拖进「应用程序」。第一次打开请右键 →「打开」。
想让猫陪你打字、扒卷纸，需要在「系统设置 → 隐私与安全性 → 辅助功能」里允许它（只知道“按了键”，不会记录按了什么）。

## 它会做什么

| 你做的事 | 猫的反应 |
|---|---|
| 移动鼠标 | 白眼球里的黑眼珠跟着鼠标转，没事做时自己东张西望 |
| 把鼠标甩得很快 | 狩猎本能：压低身子、瞳孔放大、扭屁股，然后扑过去 |
| 在它头上来回蹭 | 眯眼、脸红、呼噜呼噜（身体会轻轻震） |
| 单击 | 戳一下：跳起来再 Q 弹地落地（戳太多会生气） |
| 双击 | 才艺表演（猫翻肚皮、柴犬转圈、兔子空中转体、仓鼠装死、企鹅肚皮滑行、狐狸扎雪堆） |
| 拖拽 | 身体像麻薯一样被拉长，甩一甩会晕，松手后压扁再回弹 |
| 打字 | 搬个小键盘坐你旁边一起“打字” |
| 打字打得飞快 | 整只猫变红、头顶冒烟（过热） |
| 滚动页面 | 抱着卷纸往下扒，纸铺了一地；停下来后慢慢卷回去 |
| 每隔一段时间 | 变大伸个懒腰、去喝水，并叫你的名字提醒你也动一动、喝口水 |
| 定时提醒 | 到点跳出来喵一声：“小王，开会啦” |
| 番茄钟 | 头顶旁边浮着像素计时器；专注时不打扰你，结束时提醒你休息 |
| 头顶便签 | 右键 → 贴一张便签，一直贴在它头上 |
| 看视频时 | 「看视频模式」：躲到右下角只露半个脑袋，除了提醒不打扰 |
| AI 在干活 | Claude Code 思考时它托腮发呆，做完会开心地跳两下喵一声 |
| 想要自家宠物的花色 | 右键 → 换花色：现成花色，或者自己调底色/深色/浅色 |

另外它们有自己的生活，彼此之间也会交朋友：需求、性格、作息跟真实时间走、记得你、写日记、季节和节日、彩蛋图鉴、送你小礼物。

左下角 🐾 或系统托盘：领养、番茄钟、看视频模式、提醒设置、日记、收藏柜、彩蛋图鉴、设置。

## 和 Claude Code 联动

桌面版启动后会在本机 `127.0.0.1:47231` 开一个小接口（只有本机能访问）。
在「提醒设置」里复制配置，粘贴进 `~/.claude/settings.json` 即可；也可以手动写：

```json
{
  "hooks": {
    "UserPromptSubmit": [{ "hooks": [{ "type": "command", "command": "curl -s -m 1 http://127.0.0.1:47231/agent/thinking || true" }] }],
    "Stop": [{ "hooks": [{ "type": "command", "command": "curl -s -m 1 http://127.0.0.1:47231/agent/done || true" }] }]
  }
}
```

其他工具也能用：`/agent/thinking`、`/agent/done`、`/agent/error`、`/agent/idle`，可带 `?text=想让它说的话`。

## 开发 & 打包

- 浏览器里直接打开 `renderer/index.html` 就能试玩（左下角菜单里有“模拟 AI”）。
- 桌面版：`npm install && npm start`。
- 安装包：推到 GitHub 后，在 Actions 里运行「打包安装包」，或者打一个 `v0.2.0` 这样的标签，会自动生成 Windows 安装包和 macOS dmg（在 Releases / Artifacts 里下载）。

## 结构

```
main.js / preload.js     Electron：透明置顶窗口、点击穿透、托盘、全局键盘/滚轮、AI 状态接口、存档
build/installer.nsh      卸载时清理存档、缓存、开机自启
.github/workflows/       云端自动打包
renderer/js/
  sprites.js             程序化像素渲染：6+1 种宠物、表情、姿势、果冻形变、自定义花色
  features.js            追鼠标、呼噜、打字、过热、卷纸、提醒、番茄钟、便签、AI 反应、偷看
  pet.js / actions.js    需求驱动的生活 AI、弹簧物理（Q 弹）、眼球弹簧
  events.js / save.js    时间事件、彩蛋、日记、存档和离线推演
  interact.js / ui.js    鼠标互动识别、像素风界面、合成音效
```
