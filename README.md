# 摸鱼动物园

> 一群住在你电脑里的小动物，平时各过各的小日子，顺便陪你一起摸鱼。

住在你桌面底部的像素小伙伴：猫咪、柴犬、兔兔、仓鼠、企鹅、狐狸（还有一只要靠神秘的蛋才能孵出来）。
它们会跟着你的鼠标转眼珠、陪你打字、提醒你喝水伸懒腰，也有自己的小日子：吃饭、喝水、上厕所、睡觉、发呆、一起玩、想你、想一个人待着。

## 安装

Windows：双击安装包 → 选择安装位置 → 完成。桌面和开始菜单会有图标。
第一次运行如果 Windows 弹出“已保护你的电脑”，点「更多信息 → 仍要运行」（程序没有付费签名）。

卸载：「设置 → 应用 → 摸鱼动物园 → 卸载」。会一并删除存档、缓存和开机自启项，不留残留。

macOS：打开 dmg，把图标拖进「应用程序」。第一次打开请右键 →「打开」。
想让猫陪你打字、扒卷纸，需要在「系统设置 → 隐私与安全性 → 辅助功能」里允许它（只知道“按了键”，不会记录按了什么）。

## 发布新版本（维护者）

1. 改 `package.json` 里的 `version`，在 `changelog.json` 最上面写这一版的更新内容
2. 到 Actions →「打包安装包」→ Run workflow（勾着“发布”）
3. 自动完成：打包 → GitHub Releases → 国内线路（jsDelivr 分块）→ 更新 `version.json`；用户那边会自动收到更新

## 它会做什么

12 种小伙伴，每种都有自己的习性：
- 猫：踩奶、推杯子、追鼠标、摸头会呼噜　· 柴犬：捡球、你回来时冲过来
- 兔子、青蛙：**跳着走**；青蛙会伸舌头抓蝴蝶、泡在水碗里
- 仓鼠、刺猬：昼伏夜出；仓鼠囤粮，刺猬被吓到会缩成刺球
- 小鸡：早起早睡、低头啄地、跟在主角后面走　· 鸭鸭：摇摆走路、在水碗里洗澡
- 小猪：用鼻子拱地，常拱出小礼物　· 卡皮巴拉：几乎不动，顶着柚子泡温泉，大家都爱靠着它
- 企鹅：肚皮滑行　· 狐狸：一头扎进雪里

它们**住在电脑里**：打开时一个个从屏幕底边升起的小门里走出来，回去时也走进小门。

## 怎么控制

所有菜单都是同一份：**托盘图标 / 右下角的小爪子 / 右键任意宠物**，都能展开二级菜单（托盘菜单默认精简，可以在 设置 → 托盘菜单 里换成完整；菜单大小也能调）。

- **每只单独设置**（宠物们 → 某只）：显示/回电脑休息、乖乖待着、只露个头、设为主角
- **主角**负责提醒你、陪你打字；极简模式下只有它陪着你
- **指着宠物**：它会停下来不动，身边冒出一圈小图标：档案 / 喂 / 设主角 / 乖 / 只露头 / 回电脑 / 多选 / 更多（宠物小的时候图标也会跟着变小）
- **悬浮小按钮**（一扇小门，可以拖到任何地方，爪子菜单固定在它右边）：点一下＝收起只留主角，再点恢复；鼠标停一会儿可以切换模式、场景、季节、环境声
- **提醒**：喝水 / 站立提醒；每天或每周几的定时提醒；番茄钟
- **软件图标**：设置 → 软件图标，托盘和桌面快捷方式换成你喜欢的动物

## 显示模式：工作的时候不打扰你

- **极简**：只留主角，安安静静待在屏幕右下角那一小块
- **小场景**：任务栏上方一条，大家在里面过日子
- **全屏场景**：整块屏幕都是它们的世界；一开始打字就自动收起，Esc 也能退出
- **工作时自动安静**（默认开）：你在打字时，它们不说话、不来找你、不追鼠标，环境声自动调小
- 不在宠物、按钮、面板上的地方，点击一律穿透到你自己的窗口

## 一个活的小世界

十个地方连成一条路：**雪原 ←→ 高山 ←→ 森林 ←→ 雨林 ←→ 湖边 ←→ 草地 ←→ 农场 ←→ 沙漠 ←→ 海滩 ←→ 海底**（点两边的路牌过去，路牌上的小红点是那边有几只）。场景和宠物用同样大小的像素画，远景、中景、地面分层摆放。

每只动物都有自己的家，按自己的习性过日子——看不见的地方也在生活，会沿着路去别处觅食、串门，你切过去正好能撞见：

| 动物 | 家 | 日常 |
|---|---|---|
| 猫 | 农场谷仓阁楼 | 晨昏出门，吃猫粮、草垛边蹲老鼠、去湖边码头钓鱼；栅栏顶、屋顶晒太阳；讨厌下雨 |
| 柴犬 | 农场狗窝 | 白天巡逻、去草地疯跑刨土；下雪去雪地打滚；打雷大雨躲窝里 |
| 小鸡 | 农场鸡舍 | 天亮就醒天黑就回窝；啄玉米粒、洗沙浴、跟在大家后面走 |
| 小猪 | 农场猪圈 | 水槽吃饲料、苹果树下拱苹果、秋天去森林拱松露；泥坑打滚 |
| 兔子 | 草地兔子洞 | 晨昏吃三叶草、偷溜进菜园啃胡萝卜；胆小，下雨刮风立刻钻回洞 |
| 仓鼠 | 向日葵下的地洞 | 白天睡觉，傍晚捡瓜子塞满腮帮子囤回洞里，冬天靠存粮 |
| 狐狸 | 森林树根下的狐狸洞 | 摘浆果、到草地听田鼠一跃扎下去、下雪天扎雪堆；石头上晒太阳 |
| 刺猬 | 森林倒木下的落叶窝 | 昼伏夜出，在落叶里拱虫子；冬天冬眠 |
| 青蛙 | 湖里的大荷叶 | 傍晚呱呱叫、舌头抓飞虫、游泳；最爱下雨；冬天冬眠 |
| 鸭鸭 | 芦苇丛里的鸭窝 | 漂在湖上、扎猛子找水草、上岸理羽毛；下雨更开心 |
| 卡皮巴拉 | 湖边温泉 | 泡温泉、岸边吃草、再泡温泉；冬天头顶柚子；什么天气都无所谓 |
| 企鹅 | 雪原冰屋 | 冰窟窿里抓鱼、从雪坡上肚皮滑下来；越冷越开心 |
| 海龟 | 海底珊瑚拱门下的海草窝 | 慢慢游去海草地吃海草、趴在珊瑚顶上歇着；夏天爬上海滩晒太阳、下蛋 |
| 螃蟹 | 礁石边的大海螺 | 傍晚出来横着走找小虾、去海滩潮池觅食、在沙里挖洞、捡亮晶晶的东西 |
| 章鱼 | 沉船里的陶罐 | 夜里在珊瑚缝里摸小虾、收集贝壳摆在家门口；怕生，白天在罐子里睡觉 |

每种动物一年四季各有各的事（档案里的“一年四季”）：秋天仓鼠拼命囤粮、刺猬养膘，夏天小猪泡泥坑、海龟上岸下蛋，冬天卡皮巴拉顶着柚子泡温泉……

- 有人在家的家门口挂着小牌子（谁在家、在睡觉还是躲雨）；圆点菜单里的 **大家在哪** 列出每只在哪儿、在干嘛，点一下就过去
- 点一下家：**进去看看**（每个家里面都画了：谷仓阁楼、兔子洞、仓鼠粮仓、狐狸洞、山洞、湖底、冰屋、沉船……它们在里面睡觉、吃存粮、理毛、玩，睡够了自己从门口出去）或者 **叫出来**
- 画面跟着 **二十四节气 / 四季**、**节日**、**一天中的时刻**、**天气**（可以设城市跟随实时天气，也能固定天气和季节）
- **环境声音**：雨声、风声、鸟叫、虫鸣、溪水、湖水、雷声（可关、可调音量）
- **布置场景**：显示 → 布置这个场景…，加树、花、蘑菇、路灯、长椅、雪人、南瓜…

召唤 / 送回：
- 快捷键 **Ctrl+Alt+Shift+P**：大家回电脑 / 再按一次出来（窗口被隐藏时也能叫回来）
- 快捷键 **Ctrl+Alt+Shift+W**：大家都乖乖待着
- 存档在 `%APPDATA%\PixelNest`，每 10 分钟和每次更新前会备份到 `%APPDATA%\PixelNest-keep`

## 开发 & 打包

- 浏览器里直接打开 `renderer/index.html` 就能试玩。
- 桌面版：`npm install && npm start`。
- 安装包：推到 GitHub 后，在 Actions 里运行「打包安装包」，或者打一个 `v0.2.0` 这样的标签，会自动生成 Windows 安装包和 macOS dmg（在 Releases / Artifacts 里下载）。

## 结构

```
main.js / preload.js     Electron：透明置顶窗口、点击穿透、托盘、全局键盘/滚轮、存档和备份、软件图标
build/installer.nsh      真正卸载时才清理存档；更新前先备份存档
.github/workflows/       云端自动打包
renderer/js/
  sprites.js             程序化像素渲染：15 种宠物、表情、姿势、果冻形变、自定义花色
  features.js            追鼠标、呼噜、打字、过热、卷纸、提醒、番茄钟、便签、偷看、工作时自动安静
  art.js / biomes.js     精细像素画：树、石头、花草、珊瑚…；十个地方怎么构图
  places.js / interiors.js  每只动物的家（外面和里面）
  eco.js                 每种动物的习性、作息、觅食、躲雨、冬眠、一年四季
  pet.js / actions.js    需求驱动的生活 AI、弹簧物理（Q 弹）、眼球弹簧
  events.js / save.js    时间事件、彩蛋、日记、存档和离线推演
  interact.js / ui.js    鼠标互动识别、像素风界面、合成音效
```
