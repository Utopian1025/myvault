# ClearTask 0.4.6

公开安装包与签名更新入口。源码保存在私有仓库 Utopian1025/cleartask。

- [镜像下载 Windows 安装包](https://fastly.jsdelivr.net/gh/Utopian1025/myvault@main/cleartask/ClearTask-0.4.6-Windows.zip)
- [备用镜像](https://gcore.jsdelivr.net/gh/Utopian1025/myvault@main/cleartask/ClearTask-0.4.6-Windows.zip)
- [GitHub 安装包](https://github.com/Utopian1025/myvault/blob/main/cleartask/ClearTask-Setup-0.4.6.exe)
- [本版逐项更新说明](RELEASE-NOTES.md)

应用内：工作空间设置 → 更新。重新点击检查更新即可获取 0.4.6；下载优先使用 Fastly、Gcore 镜像。

更新清单经过 RSA 签名，客户端验证签名、长度和 SHA-256 后才允许安装。
.bin 为与 .exe 完全相同的镜像分发副本；手动安装请下载 ZIP 并运行其中的安装程序。
升级保留已有任务、备忘录与配置。

0.4.6：横向叠旗优先级、逐级返回设置、九类可配置小组件、精确横向滚轮与首尾循环选项、十三种色彩方案、逐条处理通知、SP 界面入口移除、备忘录工具栏自适应。

本目录与仓库内其他应用的版本和更新配置相互独立。
