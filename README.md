# 像素小窝 · Pixel Nest

住在你桌面底部的像素小伙伴：猫咪、柴犬、兔兔、仓鼠、企鹅、狐狸（还有一只要靠神秘的蛋才能孵出来）。
它们会跟着你的鼠标转眼珠、陪你打字、提醒你喝水伸懒腰，也有自己的小日子：吃饭、喝水、上厕所、睡觉、发呆、一起玩、想你、想一个人待着。

## 安装（给朋友用）

Windows：双击 `像素小窝-安装包-x.x.x.exe` → 选择安装位置 → 完成。桌面和开始菜单会有图标。
第一次运行如果 Windows 弹出“已保护你的电脑”，点「更多信息 → 仍要运行」（程序没有付费签名）。

卸载：「设置 → 应用 → 像素小窝 → 卸载」。会一并删除存档、缓存和开机自启项，不留残留。

macOS：打开 `像素小窝-x.x.x.dmg`，把图标拖进「应用程序」。第一次打开请右键 →「打开」。
想让猫陪你打字、扒卷纸，需要在「系统设置 → 隐私与安全性 → 辅助功能」里允许它（只知道“按了键”，不会记录按了什么）。

## 它会做什么

12 种小伙伴，每种都有自己的习性：
- 猫：踩奶、推杯子、追鼠标、摸头会呼噜　· 柴犬：捡球、你回来时冲过来
- 兔子、青蛙：**跳着走**；青蛙会伸舌头抓蝴蝶、泡在水碗里
- 仓鼠、刺猬：昼伏夜出；仓鼠囤粮，刺猬被吓到会缩成刺球
- 小鸡：早起早睡、低头啄地、跟在主角后面走　· 鸭鸭：摇摆走路、在水碗里洗澡
- 小猪：用鼻子拱地，常拱出小礼物　· 卡皮巴拉：几乎不动，顶着柚子泡温泉，大家都爱靠着它
- 企鹅：肚皮滑行　· 狐狸：一头扎进雪里

它们**住在电脑里**：打开时一个个从屏幕底边升起的小门里走出来，回去时也走进小门。

## 怎么控制

所有菜单都是同一份：**托盘图标右键 / 左下角的小爪子 / 右键任意宠物**，都能展开二级菜单。

- **每只单独设置**（宠物们 → 某只）：显示/回电脑休息、乖乖待着（不乱跑不乱跳）、只露个头、设为主角
- **主角**负责提醒你、陪你打字、AI 联动
- **工作模式**：大家都乖乖待着　·　**只露个头**：沉到屏幕底下只露半个脑袋
- **提醒**：喝水 / 站立提醒，间隔可选或自定义；每天定时提醒；番茄钟
- **背景**：草地 / 森林 / 海边 / 雪地 / 星空 / 木地板，可调高度，随时关

召唤 / 送回（故意设计成平时不会误触的操作）：
- 快捷键 **Ctrl+Alt+Shift+P**：大家走进小门回电脑 / 再按一次出来（窗口被隐藏时也能叫回来）
- 快捷键 **Ctrl+Alt+Shift+W**：开关工作模式
- 鼠标：在**屏幕最底边快速左右来回晃**鼠标（1 秒内折返 5 次以上）

## 和 Claude Code 联动

菜单 → AI 联动 → **一键接入**（会先备份你原来的 ~/.claude/settings.json）。之后：
- 你提问 → 主角托腮陪它一起想
- AI 做完 → 主角跳起来喵一声告诉你
- AI 需要你点“允许” → 主角转过来朝你招手

面板里有“试一试”按钮，不装 AI 也能看效果。其他工具也可以直接访问 `http://127.0.0.1:47231/agent/thinking|done|waiting|idle`。

## 开发 & 打包

- 浏览器里直接打开 `renderer/index.html` 就能试玩（左下角菜单里有“模拟 AI”）。
- 桌面版：`npm install && npm start`。
- 安装包：推到 GitHub 后，在 Actions 里运行「打包安装包」，或者打一个 `v0.2.0` 这样的标签，会自动生成 Windows 安装包和 macOS dmg（在 Releases / Artifacts 里下载）。

## 结构

```
main.js / preload.js     Electron：透明置顶窗口、点击穿透、托盘、全局键盘/滚轮、AI 状态接口、存档
build/installer.nsh      卸载时清理存档、缓存、开机自启
.github/workflows/       云端自动打包
renderer/js/
  sprites.js             程序化像素渲染：6+1 种宠物、表情、姿势、果冻形变、自定义花色
  features.js            追鼠标、呼噜、打字、过热、卷纸、提醒、番茄钟、便签、AI 反应、偷看
  pet.js / actions.js    需求驱动的生活 AI、弹簧物理（Q 弹）、眼球弹簧
  events.js / save.js    时间事件、彩蛋、日记、存档和离线推演
  interact.js / ui.js    鼠标互动识别、像素风界面、合成音效
```
