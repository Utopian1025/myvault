# ClearTask 0.4.6

- 高、中优先级改为水平重叠的三面、两面矢量旗帜，统一状态栏的主题色、线条与底色。
- 设置详情与子详情保留分类导航，提供逐级返回；天气和数据库属性配置使用同一页内导航。关闭设置时统一释放保留页面。
- 移除数据页和旧菜单中的 SP 导入、来源记录入口；已有迁移数据和备份保持兼容。
- 小组件支持精确横向滚轮、拖动、分页点；增加首尾循环开关，侧边栏上下位置及边距设置。
- 九类组件：日期天气、今日概览、重点任务、近期安排、项目进度、倒计时、随手记、完成回顾、文字卡。支持 1–12 张卡片、标题及内容配置、项目/日期选择和拖动调序。
- 十三种界面色彩方案覆盖中性、科技、自然、暖色、活力、创意与莫兰迪；模块可分别选择。
- 通知铃铛显示未读数量；通知中心改为逐条已读、延后与查看任务的卡片，保留全部已读。逾期与未读继续独立统计。
- 修复关闭窗口或清空视图时，悬停动画访问已移除表格行造成的异常。
- 修复备忘录工具栏被横向滚动条遮挡：工具按钮按可用宽度换行，整体高度自适应。
- 六张宣传图由虚拟数据的实际界面生成，标注 0.4.6。

# ClearTask 0.4.0

本版更新与逐项反馈。源码在私有仓库；公开发布仅包含安装包、签名更新清单和本说明。

## 验证范围

包含应用回归、专项检查、隔离安装升级回退、实际界面检查。SP备份副本重新导入后2763项字段对账无差异，19个视图1250个单元格无数据变更。原始备份保持不变。

性能已针对重绘、日期缓存、窗口动画绘制和日历缓存优化，但不宣称所有电脑均零延迟；实体Logi Master手感、公司电脑以及不同缩放下的最终系统任务栏图标需在对应环境确认。SP外部插件和第三方集成不会自动启用。
