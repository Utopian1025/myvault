# ClearTask 0.4.9

- 备忘录：中文组词期间暂停富文本读取及自动保存；保存不再重建笔记列表项，保留焦点与选区。
- 工具栏：分组布局、加粗/斜体/下划线状态、字体字号颜色、段落对齐、清单表格附件、撤销重做。
- 标题移到工具栏下方，与白色正文纸面用细线分隔；标题格式与对齐单独保存，Tab / Shift+Tab 切换标题正文。
- 设置新增备忘录默认字体、标题及正文字号、正文默认加粗；设置区支持自定义颜色及恢复跟随全局。
- 天气：Open-Meteo 主源、MET Norway 备用，最近有效数据缓存、时间标记和手动重试；失败不伪造实时天气。
- 小组件：随手记可指定备忘录，默认直达最近编辑的一篇；卡片内容向左上收紧；快速切换不再重复捕获半张过渡画面。
- 新增法定节假日倒计时，包含 2027 放假安排；普通周末和调休工作日不作为节日。
- 到点提醒始终提交 Windows 通知（系统勿扰或通知权限可能抑制横幅）；通知使用当前品牌图标，升级替换旧图标文件路径。
- 保留 0.4.8 多源更新、签名及完整性校验。

天气数据：Open-Meteo、MET Norway，模型天气/预报，CC BY 4.0。法定节假日数据整理：NateScarlet/holiday-cn，来源公告见数据内 papers。
