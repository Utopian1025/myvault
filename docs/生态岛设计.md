# 生态岛设计（0.39 起）

浮岛是活的：有自己的年龄，按现实的日子一天天长，没人玩也照样长。代码在 `renderer/js/ecology.js`（`PP.ECO`）。

## 1. 时间和生长速度
- 岛的「生长」按**生长日**累计：一个普通好年景大约 300 生长日；整个生长按 **50 年**设计。
- 每天能长多少（`plantRate`）看气温：0° 以下几乎不长（0.04），6~12° 慢（0.55），18~28° 最旺（1.2），34° 以上热得长不动（0.55）。
- 天气：下雨 ×1.2；下雪 ×0.6；连续 10 天以上不下雨又热（干旱）×0.65。
- 正在玩：每分钟按**实时天气**（open-meteo 的气温和天气）算一次。
- 没打开的那些天：下次打开时一天天补算，每天按**当月的气候**（月均温、下雨机会）估，暴风雨在夏天随机发生。
- 季节跟现实同步（`PP.season`）。

## 2. 植物
| 东西 | 怎么长 | 时间尺度 |
|---|---|---|
| 苔藓 | 石头、树皮、屋顶上越长越厚 | 2~3 年长满，之后随季节 |
| 藤蔓 | 小屋墙上的藤越爬越高 | 4~5 年 |
| 小树林 | 每棵树有年纪：树苗 → 小树 → 成材（约 7~10 年）→ 老树（40 年+） | 十几年 |
| 林子扩张 | 春天成材的树落种，空位冒出新树苗 | 每年 |
| 老树倒下 | 40 多年的老树遇上暴风雨会倒，变成长苔长蘑菇的倒木；三年后烂掉的地方又冒新苗 | 几十年 |
| 神树 | 千年老树，五十年里树冠还会往外撑、在大枝之间多分出新枝（最多 12 根） | 50 年 |
| 菜地 | 种下的菜按原来的成熟时间长（`life.js`） | 半小时到几小时 |

## 3. 动物
- **鱼**：每种鱼有自己的数量（logistic 增长，水里最多能有多少按稀有程度：常见 60、少见 26、稀有 9、传说 3）。春天水温 14° 以上产卵，数量涨得快，水里出现一群群小鱼苗；冬天几乎不长。钓走一条少一条，过一阵会长回来。水里多的鱼更容易来咬钩，水下看到的鱼也更多。
- **蚯蚓**：看土湿不湿（下雨变湿，晴天慢慢变干）、冷不冷（冻土时钻得很深）。
- **红虫、小河虾、浮萍**：看水温。**蚱蜢**：夏秋白天。**蟋蟀**：七到十月的夜里。
- 找过一次会少一些，过一阵再聚回来。

## 4. 东西都是从哪来的
- **种子**：
  - 收菜时留种：向日葵、瓜果里有籽；玉米留几粒；胡萝卜、卷心菜要等一棵抽薹开花才有（不是每次都有）；郁金香分球。
  - 春秋候鸟在岛上歇脚时带来别处的种子。
  - 探险带回来的。
  - 加工工坊里也能专门留种。
- **鱼饵（12 种）**：
  - 工坊里能找的：
    - 蚯蚓：堆肥箱里翻（厨房菜叶、收菜剩的茎叶堆出来的）。
    - 蚱蜢：夏秋白天草地里扑。
    - 蟋蟀：夏末秋天夜里循着叫声捉。
  - 池边能找的：
    - 红虫：用细网捞池底淤泥。
    - 浮萍：池面上捞。
    - 小河虾：放虾笼，过几个小时收（放得越久、水越暖越多）。
  - 钓到的小麦穗鱼、青鳉放进活饵桶，就是活麦穗鱼。
  - 工坊里做的：
    - 面团：玉米磨面。
    - 蜜玉米粒：玉米加蜂蜜。
    - 菜叶团：卷心菜。
    - 木头小拟饵：用柴刻、用草莓汁上色。
    - 肉干：原来就有。
- **柴**：暴风雨吹断的枯枝（会自动捡回柴堆）。
- **蘑菇**：秋雨后长在树根和倒木边。
- **蜂蜜**：蜂箱。**鸡蛋**：屋顶鸟巢。

## 5. 建筑的生长：住在岛上的大家添置的东西
按岛长了多少年解锁（`ADDS`）：
| 时间 | 添置的东西 |
|---|---|
| 约 1 个月 | 回廊柱子上的鸟屋 |
| 半年 | 码头到栈道的彩旗 |
| 1.2 年 | 石灯笼 |
| 2.5 年 | 秋千 |
| 5 年 | 池上第二座小木桥 |
| 10 年 | 神树大枝上的观鸟屋 |

以后还会接着加。

## 6. 在哪儿看
成长面板 →「浮岛生长」页，能看到以下这些：
- 岛几岁了、现在长得快不快（为什么）
- 每样东西长到哪一步、水里每种鱼多不多
- 东西从哪来、最近发生的事（暴风雨、候鸟、新树苗……）

## 7. 随机性（0.40）
世界本来是随机的。每座浮岛出生时有自己的随机种子（`st().rs`，PRNG `rng()`），之后的每一次「掷骰子」都从它往下走：同样的季节天气，在不同的岛上会走出不同的结果；离线补算时也一样用它，所以每座岛的历史各不相同。

| 事件 | 什么时候可能发生 | 结果（会留下来的） |
|---|---|---|
| 雷击 | 暴风雨 | 劈中岛边一棵大树 → 焦黑树桩（3 年后烂掉、原地冒新苗）；或者劈在神树上留下一道焦痕 |
| 流星雨陨石 | 8 月、12 月 | 岛上某处落一块发光的小陨石，走过去能捡（陨石碎片） |
| 分蜂 | 春天、暖和 | 岛边某棵大树上多一个野蜂窝；之后隔一阵树下会滴一罐蜜 |
| 野鸭 | 春夏 | 一对野鸭（有时带小鸭）住进古城之池，几个月后飞走 |
| 蘑菇圈 | 秋天下雨后 | 草地上一圈蘑菇，十来天消失，能捡 |
| 野花 | 春、秋 | 风或候鸟带来的种子发芽：野草莓、野向日葵、虞美人、蒲公英、雏菊一小片；每年春天往外长、往旁边蔓延；野草莓六月结果能摘 |
| 藻华 | 又热又旱 | 池水发绿，鱼慢慢变少；下几场雨后恢复 |
| 风筝 | 大风天 | 一只不知谁家的风筝挂在树梢上，几个月 |
| 神树开花 | 每年四月掷一次（约 18%） | 春天满树白花；那年秋天结金色果子落在树下（神树的果子） |
| 萤火虫 | 每年五月定下当年多少（看春天雨水 × 运气） | 五六月夜里的萤火虫有多有少 |
| 小树枯死 | 大旱 | 一棵小树没熬过去 |
| 新树的树种 | 每次冒新苗 | 多半是橡树，也可能是白桦、枫树、松树；高矮、歪的方向各不一样 |
| 彩虹 | 雨停、白天放晴 | 约 65% 的机会，天边挂一道彩虹 25 分钟 |
| 罕见的鱼 | 每次钓上鱼 | 约 1.2% 金色个体、1.3% 白化个体、2.5% 巨型个体，记进图鉴 |

成长面板「浮岛生长」里的「这座岛独有的经历」列出这座岛上现在有的、发生过的这些。
