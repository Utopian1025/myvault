# ClearTask 0.4.0

本版更新与逐项反馈。源码在私有仓库；公开发布仅包含安装包、签名更新清单和本说明。

## 验证范围

包含应用回归、专项检查、隔离安装升级回退、实际界面检查。SP备份副本重新导入后2763项字段对账无差异，19个视图1250个单元格无数据变更。原始备份保持不变。

性能已针对重绘、日期缓存、窗口动画绘制和日历缓存优化，但不宣称所有电脑均零延迟；实体Logi Master手感、公司电脑以及不同缩放下的最终系统任务栏图标需在对应环境确认。SP外部插件和第三方集成不会自动启用。
