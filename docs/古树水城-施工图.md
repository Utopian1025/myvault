# 古树水城：施工图（从底层往上盖）

方案图：https://claude.ai/artifact/J4pBQpcshRFXyJxX7BVGhz（剖面、平面、每个模块的道理）。
用户 11-24 说：「从建筑结构开始，从底层开始重新设计」。所以按下面的顺序一层层盖，**全部做完、测完才发版**。

## 坐标约定（跟引擎一致）
- 世界坐标 u（东为正）、v（南为正）、z（上为正）。岛心 CEN = (24, 24)。
- 楼层高度 Z = [-16, 0, 15, 30]：
  - L0 −16：在水下，不放房间，只能潜水去。
  - L1 0：根间层，就是水面上那一层。
  - L2 15：第一层大枝。
  - L3 30：第二层树杈，也是树心楼梯的顶。
- 角度 θ = atan2(Δv, Δu)：东 0°，南 90°，西 180°，北 −90°。

## 竖向（从下往上）
| 高度 z | 是什么 |
|---|---|
| −50 ~ −36 | 岛底：岩体收成尖，粗根缠着往下垂；浮石（发光的蓝石头，半径约 4）在 z≈−40，被一圈根抱着，从广场中央的裂口能看见它 |
| −26 | 古城地面（城里的街道、广场）。盆地底 |
| −26 ~ −2 | 水下古城的房子、钟塔、神殿等（大多数顶在水面以下 2～8） |
| −1.2 | 水面 WL |
| 0 ~ 3 | 露出水面的古城屋顶和台阶：码头、踏石、梯田、温室穹顶的下半；根间的地板 z = 0 |
| 0 ~ 56 | 大树树干（空心，里面是螺旋楼梯，到 L3 为止） |
| 15 / 30 | 枝上的房子 |
| 40 ~ 62 | 树冠；舵台在树干顶 |

## 平面
- **岛的外沿（岩体边）**：半径 ≈ 30，不规整。
- **盆地（水）**：半径 ≈ 26.5，边上是古城的城墙一圈；城墙顶在 z≈0～2，有的地方塌了。
- **大树**：
  - 树干中心在岛心 (24, 24)。
  - 树干在古城广场的高度半径 ≈ 9（连着板根），水面处 ≈ 7，L1 往上 6.5，到 z≈40 收到 5。
  - 空心：内半径 4.4，从 z≈−1 一直到 L3。
- **五条大根**：从树干伸出去，方向 θ = −90°、−18°、54°、126°、198°。它们在水面附近拱起来，一头扎进古城，一头搭在城墙上。
- **五个根间**：在两条根之间，中心半径 ≈ 14，地板 z=0，搭在露出水面的古城地基上：

  | 方向 | 房间 | 为什么在这儿 |
  |---|---|---|
  | −54°（东北） | 洗衣房 | 靠东边出水口 |
  | 18°（东偏南） | 厨房 + 餐厅 | 挨着梯田 |
  | 90°（南） | 门厅 | 正对码头 |
  | 162°（西南偏西） | 柴房 + 工坊 | |
  | −126°（西北） | 地窖：储藏 / 腌菜 / 石炉 | 背阴 |

- **露出水面的古城**：
  - 温室穹顶：θ 135°，半径 21；天文台的玻璃穹顶，穹顶下半在水里。
  - 梯田：θ 40°～70°，半径 19～26，古城的台阶街道，三级，z = 0 / 1.6 / 3.2。
  - 钟塔顶：θ −40°，半径 18，塔顶露出水面到 z≈8，挂着钟。
  - 码头：θ 90°，从半径 24 伸到 34，搭在古港口的石柱上。信箱、热气球、钓鱼都在这里，石阶从这里下水。
  - 出水口和水车：θ −8°，在城墙缺口处，水流出去挂成瀑布。

## 水下古城（盆地底 z = −26）
- **广场**：中心半径 11 的圆，铺着石板，大树从中间长出来，树根把石板拱裂；广场中央一道裂口，往下能看见浮石。
- **街道**：6 条放射街，方向 θ = 0°、60°、120°、180°、240°、300°，宽 3。外圈一条环街，半径 19。
- **地标**：
  - 钟塔：θ −40°，半径 18，方塔，见上。
  - 神殿：θ 180°，半径 16，一排柱廊加三角山墙，顶在 z≈−12。
  - 天文台：温室那座，圆塔加玻璃穹顶，穹顶露出水面。
  - 拱桥：θ 110°，半径 15，跨过一条旧水渠。
  - 城门：θ 90°，半径 26，在城墙上，对着码头。
- **民居**：约 24 栋，分布在放射街和环街之间的街区里。石墙，有的有屋顶、有的塌了一半。门是拱形，窗是深色的洞，屋顶和墙头长着水草和苔藓。
- **城墙**：沿盆地边一圈，墙顶 z≈−2～+1。

# 第②③步：定好的数字（照着盖）

## 树干和楼梯
- **树干**：中心 (24,24)。L1～L3 外半径 8，空心内半径 6，正中一根心柱半径 1.6。水面以下往下越来越粗，连着板根伸进古城广场（半径 9）。
- **螺旋楼梯**：踏步在半径 1.8～5.6 之间，一层转 450°（坡度约 27°，不陡），每级升 0.6。
  - **SP1**：L1→L2，从 θ=90°+12° 转到 90°+438°。
  - **SP2**：L2→L3，从 180°+12° 转到 180°+438°。
  - 每层到达处是一块平的落脚台（落脚角 ±12°），门就开在那个方向的树干壁上：
    - L1 门朝南（90°）
    - L2 门朝西（180°）
    - L3 门朝北（270°）
  - 门洞都是正南、正西、正北，所以可以用不转角度的长方形门。
- **引擎要改的地方**：楼梯加一种 `spiral` 类型，字段是 `{cu,cv,r0,r1,ang0,ang1,a,b}`。
  - `rampEnds` 返回门外一点。
  - 伙伴走楼梯时沿着弧线上的一串点走，每个点带自己的高度。
  - `inRampF` 改成判断在不在环带里。
  - 楼梯侧面的碰撞检查跳过（第一人称靠画出来的台阶撞）。

## 树腰平台（一圈木回廊，绕着树干）
- 用一种新的「环形地面」：`RINGS = [{lv, r0, r1}]`，`floorAt` 认它。

- L3：半径 8～11，z=30。
