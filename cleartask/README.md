# ClearTask

ClearTask 的公开安装包与签名更新入口。源码保存在私有仓库 Utopian1025/cleartask。

下载：[ClearTask 0.4.0](https://github.com/Utopian1025/myvault/releases/tag/cleartask-v0.4.0)。逐项更新和验证范围见该版本的 RELEASE-NOTES.md。

`latest.json` 为 RSA 签名更新清单，客户端验证签名、长度与 SHA-256 后才允许安装。`.bin` 是与 Release 安装包字节完全一致的 CDN 分发副本。

此目录与仓库其他应用的版本、更新配置相互独立。
