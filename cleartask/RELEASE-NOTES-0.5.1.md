# AIO Workspace 0.5.1

All in One。继续使用原工作区、更新身份和数据路径，已有任务与备忘录不需要迁移。

- 品牌改为 AIO Workspace；恢复并精修黑白勾选图标，覆盖应用、托盘、通知和安装维护入口。
- 备忘录目录与编辑区等高、工具栏对齐；默认字体颜色可调；最近删除位于目录工具栏。
- 长文改用固定的原生编辑视口，避免输入时反复调整编辑器高度；标题随文档滚动，Tab 进入正文。
- 单行备忘录工具栏支持横向滚动，统一矢量图标的尺寸和间距。
- home 使用独立房屋图标，展示实际任务、项目进度、七日完成趋势和最近备忘录。
- 重复系列管理按当前项目隔离。
- 底部导航改为胶囊轮廓，背景模糊由 Windows 合成器按轮廓裁切；选中项使用强调色与实心图标，支持弹性指示、收缩、展开和拖入侧边栏模块。
- 设置分组采用统一的展开、收起和逐级返回逻辑。
- 优化非任务页面切换；修复启动时首页覆盖已选项目、标签的问题。
- 使用统一中性底色与九种强调色；修复设置标题黑块、返回按钮文字截断及透明按钮周围的矩形底色。
- 首页与备忘录使用有界页面缓存，返回备忘录保留编辑器、光标和滚动位置；数据变化会使缓存失效。

玻璃效果的范围：底部导航使用实时系统合成模糊；设置页使用进入时采样的工作区模糊背景，正文保持实色以保证可读性。关闭系统透明效果或不支持合成时使用实色后备方案，并非整个窗口透视桌面。

已在隔离虚拟数据窗口检查微信输入法中文候选框、连续输入及自动保存；正式任务数据未参与测试。
